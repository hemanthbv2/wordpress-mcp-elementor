HOW TO IMPORT TO ANY WORDPRESS ELEMENTOR SITE (NO BROKEN IMAGES):
1. In your WordPress Admin, go to:
   Templates -> Saved Templates -> Import Templates
2. Click "Choose File" and select any of the .json or .zip template files.
3. Click "Import Now".
4. Elementor will automatically download all 48 high-res assets directly from the
   public GitHub CDN repository (hemanthbv2/rvpu-assets) into your Media Library!
   No empty placeholders or broken links!
5. Create a new Page (or edit an existing one), set Page Layout to "Elementor Canvas",
   click the folder icon (Add Template), go to "My Templates", and click "Insert".

ASSETS INCLUDED:
All 48 high-resolution images, logos, mascots, and illustrations exported
from Figma at 2x resolution are also bundled in the 'images/' directory for offline use.
