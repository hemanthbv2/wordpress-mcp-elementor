========================================================================
RV PU COLLEGE HAROHALLI - ELEMENTOR HOMEPAGE TEMPLATE & ASSET PACKAGE
========================================================================

This package contains everything needed to import the complete RV PU College
Harohalli homepage with 100% of its images, styling, widgets, and responsive
tablet/mobile layouts into any WordPress + Elementor website.

CONTENTS OF THIS PACKAGE:
-------------------------
1. rvpu-homepage-elementor-template.json
   - The complete Elementor template JSON for import via Elementor.

2. images/ (Directory with 44 Full-Resolution Assets)
   - Contains all logos, hero elements, mascots, backgrounds, patterns,
     course icons, student photos, event photos, footer icons, and arrows.

3. import-rvpu-template.php (1-Click Automated Importer)
   - Automatically uploads all 44 images to your WordPress Media Library,
     links them into the template JSON with local attachment IDs, creates
     the page, and saves the template to your Elementor library.

------------------------------------------------------------------------
HOW TO IMPORT (CHOOSE EITHER METHOD):
------------------------------------------------------------------------

METHOD 1: AUTOMATED 1-CLICK IMPORT (RECOMMENDED - GUARANTEES ALL IMAGES)
------------------------------------------------------------------------
1. Copy or upload this unzipped folder (containing `import-rvpu-template.php`,
   `rvpu-homepage-elementor-template.json`, and the `images/` folder) to your
   WordPress root directory (the same folder where `wp-config.php` and `wp-load.php` are).
2. Open your browser and go to:
   https://your-website.com/import-rvpu-template.php
3. The script will automatically:
   - Import all 44 images into your WordPress Media Library.
   - Map all local attachment IDs into the Elementor layout.
   - Create the published page: "RV PU College Harohalli - Homepage".
   - Save the template into your Elementor "Saved Templates" library.
4. Delete `import-rvpu-template.php` after running for security.

------------------------------------------------------------------------
METHOD 2: MANUAL ELEMENTOR IMPORT
------------------------------------------------------------------------
1. Go to your WordPress Admin -> Media -> Add New.
2. Drag and drop all 44 files from the `images/` folder into your Media Library.
3. Go to WordPress Admin -> Templates -> Saved Templates -> Import Templates.
4. Select `rvpu-homepage-elementor-template.json` and click "Import Now".
5. In Elementor, edit any page, click the Folder icon -> My Templates, and
   insert "RV PU College Harohalli - Homepage Template".
